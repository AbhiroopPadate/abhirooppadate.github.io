## 🚀 Featured Projects

### 📡 Wi‑Fi CSI Human Activity Recognition
End-to-end Linux-based wireless sensing pipeline using Intel AX200 adapters: packet capture → CSI extraction → preprocessing → PCA → Transformer-based models for real-time device‑free human activity recognition.

**Tech:** Python · TensorFlow · Linux · Intel AX200 · Signal Processing · Deep Learning

---

### 👁️ Blind Cap — ChaturChakshu
An AI-powered wearable assistive device that integrates LiDAR, YOLOv8 and LLMs to provide contextual, real-time audio guidance for visually impaired users.

**Tech:** Python · YOLOv8 · Hugging Face · LoRA · Embedded AI

---

### 🌳 Deforestation Prediction
A machine learning + GIS framework using multi-temporal Sentinel-2 imagery and NDVI for predicting forest cover change.

**Highlights:** 95.7% Balanced Accuracy · 0.992 ROC-AUC
